# SDM2.0 日志模型调查视图补充

> **文档定位：** 本文档是 `05-SDM2.0-日志模型概念研究.md` 的补充材料，用于研究日志模型在产品查询、检索和调查视图中的字段组合方式。
>
> **核心说明：** fieldset 不属于日志概念模型的核心对象，也不是事件角色。它是一组面向调查场景的推荐展示字段，帮助分析师快速切入问题。

---

## 一、fieldset 是什么

`fieldset` 可以理解为某类调查场景下的"推荐字段组合"。

日志模型中的事件字段可能分布在多个命名空间中：

```text
metadata.*
source.*
carrier.*
target.*
observer.*
related.*
network.*
email.*
dns.*
http.*
file.*
process.*
```

不同调查场景关注的字段不同。fieldset 的作用是把高频字段预先组织成视图模板，让分析师不用每次从完整字段集中手动挑选。

---

## 二、fieldset 的定位

| 维度 | 说明 |
|------|------|
| **不是什么** | 不是事件角色，不是实体类型，不是新的数据对象 |
| **是什么** | 面向产品体验的字段组合模板 |
| **服务对象** | 安全分析师、检测工程师、调查工作台 |
| **主要用途** | 列表展示、快捷查询、调查视图、规则编写辅助 |
| **与日志模型关系** | 基于日志模型字段组织视图，但不改变事件自身语义 |

## 三、标准 fieldset

### 3.1 sdm_fieldset.core（通用概览）

适用于大多数日志列表、搜索结果页和事件详情页的首屏摘要。

```text
事件类型
发生时间
厂商
发起方用户名
发起方 IP
目标 IP
目标端口
```

### 3.2 sdm_fieldset.endpoint（端点调查）

适用于 EDR、主机安全、进程执行、文件活动等端点调查场景。

```text
事件类型
发生时间
发起方主机名
发起方操作系统
载体进程名
进程命令行
进程 MD5
目标主机名
目标域名
```

### 3.3 sdm_fieldset.network（网络调查）

适用于防火墙、NDR、代理、流量、DNS、HTTP 等网络调查场景。

```text
事件类型
发生时间
源 IP
源端口
源主机名
载体协议
应用层协议
目标 IP
目标端口
目标主机名
目标 URL
目标域名
上下行字节数
```

### 3.4 sdm_fieldset.identity（身份认证调查）

适用于登录、登出、认证失败、账号异常、权限访问等身份调查场景。

```text
事件类型
发生时间
用户名
用户类型
发起方设备 IP
发起方主机名
目标服务名称
服务类型
认证结果
```

## 四、产品使用方式

### 4.1 列表展示

当用户选择不同调查视图时，产品可以自动切换字段列：

```text
网络调查视图     → sdm_fieldset.network
端点调查视图     → sdm_fieldset.endpoint
身份认证调查视图 → sdm_fieldset.identity
```

### 4.2 快捷查询

fieldset 可以作为搜索页面的查询辅助，让用户从场景进入，而不是从字段名进入。

```text
用户选择"端点调查"
  → 系统优先提示主机、进程、命令行、文件 hash 等字段
```

### 4.3 规则编写辅助

检测工程师编写规则时，可以基于 fieldset 快速确认某类场景下的推荐字段。

```text
PROCESS_LAUNCH 规则
  → 优先参考 sdm_fieldset.endpoint

NETWORK_CONNECTION 规则
  → 优先参考 sdm_fieldset.network
```

## 五、与概念模型的关系

日志概念模型回答：

```text
事件是什么？
有哪些参与角色？
实体如何提供上下文？
告警如何反向引用事件？
```

调查视图补充回答：

```text
不同调查场景优先看哪些字段？
产品列表应该展示哪些字段？
搜索和规则编写如何减少字段选择成本？
```

因此，fieldset 应保持为补充材料，而不进入日志模型的核心概念定义。
